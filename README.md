I made a home page that displays a welcome messge and introduction to the store. The page is styled using react bootstrap and contains a button that navigates to the product listing page. 

I created a product listing page. I made a GET API call to https://fakestoreapi.com/products in order to get product details for products in my store. I like that Axios automatically transforms request and response data to and from JSON and I like the error handling capabilities so I chose Axios over Fetch. I grabbed the product image, title, and price and mapped to and displayed them with cards. I added a view details button to the cards. I don't know if I did this in a weird way or not, but I added a link element to the card and used the d-flex (display flex) class in combination with justify-content-center. This made the link element a Flex container and then tells the Flex container to align the child elements in the center, which would be the View Details button in this case. 

I made a product details page. When you click view details on a product on the product listing page, you are routed to the product details page with that product's id in the url /products/${product.id}. The product details page uses useParams() to extract that id from the url. I then make a GET API call to https://fakestoreapi.com/products/:id passing in the product id that I extracted from the url. I extract the product's image, title, description, category, and price from the response and display them. The page handles loading states and error messages. I added two buttons. There is a delete button that on click will cause a modal to popup. If the user confirms that they want to delete the product then the app will call the https://fakestoreapi.com/products/${id} API using the DELETE method using AXIOS. The product doesn't actually get removed as this is a mock test. I log the response status to the console and then I display an alert after the the delete call is finished and then route the user back to the product listing page. When the add to cart button is clicked, I display an alert that tells the user that the product has been added succesfully. I did not add an optional cart and the button has no real functionality outside of the alert.

I created an add product page. On that page I included a form with react bootsrap form components for product title, price, description, and category. I put a success variant submit button that displays a spinner on click to show that the request is processing. When the submit button is clicked a POST API call is sent to https://fakestoreapi.com/products with the form data using AXIOS to create a new product (a new product is not actually created as this is a mock call). After the API call is completed, an alert stating that the product was added succesfully and then the form is cleared.

The instructions did not say to put an edit button anywhere (like on the product listing page or product details page). So I didn't end up putting one anywhere. I can go back and actually put a link to the Edit Product page if you want. Right now the only way to get there is to manually type in the url (i.e. /editproduct/5). I borrow code from my product listing page to load product data onto the edit page. I reuse a lot of code for the actual edit form from the add product page.
